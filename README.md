> **ADVISORY DISCLAIMER**: This system is for educational and informational purposes only. All outputs are model-generated recommendations requiring human review and judgment. This is NOT financial advice. Past simulated performance does not predict future results. No live trading execution is connected to this system.

---

## Overview

A GitHub-based, Python-powered multi-agent investment committee for managing a **$100,000 Roth IRA model portfolio**. The system operates like an adaptive macro hedge fund with daily monitoring, recursive learning, and advisory-only outputs.

**Not a daily scalping system.** Medium- and long-term investment orientation with daily monitoring.

---

## Investment Philosophy

**Core Mantra:** Long-term scarcity bias, macro regime awareness, technical confirmation, momentum orientation, contrarian sentiment analysis.

**Primary Optimization Objective (in order):**
1. Asymmetry
2. Liquidity-adjusted returns
3. Macro alignment
4. Technical confirmation
5. Scarcity exposure
6. Sentiment contrarian opportunity
7. Long-term portfolio value

**Valuation** is secondary. Forward P/E preferred. Strong macro + scarcity + momentum can outweigh valuation concerns.

## Key Principles

- **Signal ≠ Action**: Always separate signal from recommended action
- **Dissent matters**: Strong agent disagreement reduces confidence and sizing
- **Bubbles**: Meet with skepticism, ride with trimming plan, exit gradually
- **Options**: Take profits more aggressively due to theta decay
- **Cash**: Deploy into STRC-like instruments; never idle without purpose
- **Philosophy**: The system must challenge its own scarcity bias every cycle
